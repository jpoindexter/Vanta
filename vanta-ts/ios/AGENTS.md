# Native iOS dependency maintenance

Read the repository and vanta-ts instructions first. Keep Capacitor core, iOS,
CLI and the native Swift dependency on the same exact reviewed version.

`App/CapApp-SPM/Package.swift` is generated by `npm run mobile:sync`. Resolve
that package with SwiftPM, then refresh the checked-in Xcode workspace
`Package.resolved` from the actual resolution. Never invent a revision/hash.
Run `node --test scripts/mobile-dependency-alignment.node-test.mjs` from vanta-ts.

Sync/resolution and an iOS compile/device run are separate evidence. Do not
change signing, developer accounts or device provisioning for dependency work.
Keep generated web assets and local Swift caches out of source commits.
