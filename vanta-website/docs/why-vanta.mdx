# Why Vanta

Vanta is a **full-capability personal operator**: broad enough for research, files,
software, documents, communication, schedules, business, media, life administration,
and automation; specialized in preserving the thread and transferring safe responsibility
when human attention and executive function are finite.

Here's what that buys you — each point is a concrete, checkable claim, not a slogan.

### A boundary the agent must not be able to talk its way past

Vanta's [Rust kernel](/kernel) risk-classifies actions into allow / ask / block and is
intended to anchor scope, approvals, and audit evidence independently of model prose.
The July 30 audit found secondary effect paths that still need hard mediation and
credential isolation, so this remains a release contract rather than an absolute
present-tense claim. The repository product-acceptance record keeps the executed
evidence and gaps separate.

### It knows the goal before it acts

A goal ledger plus a dependency graph mean Vanta carries *what it's trying to do* into
every step — so an action that doesn't serve the goal is visible as such, before it runs.
See the [agent loop](/agent-loop).

### Built around executive function, not against it

Most agents assume the bottleneck is capability. Human executive capacity is finite and
variable for everyone. Neurodivergent and disability experience exposes the sharpest
failures and supplies curb-cut design requirements; the resulting support is available
to everyone by default without diagnosis gating:

- **Automatic adaptation** — observable task cues such as stuckness, corrections, overload,
  and reorientation needs privately reshape the current turn without inferring a diagnosis or
  writing a permanent profile fact.
- **Self-redirect** — repeated failures and research-only action loops receive one bounded
  change-of-approach directive before the existing hard stop.
- **Task initiation** — stuck or staring? Vanta prescribes the single smallest concrete
  next step, not vague encouragement.
- **Choice reduction** — a backlog surfaces as the top 3 by effort, smallest first, with
  the rest hidden — never a wall of options.
- **Working memory** — it re-anchors the goal and current step across a long session, and
  after any context compression, so you don't lose the thread.
- **Closure over novelty** — outcome state, ownership, waiting conditions, and evidence
  preserve the thread without treating Git activity as a proxy for life progress.
- **Time-blindness help** — estimates come as best / realistic / worst ranges with named
  hidden costs, never a single misleading number.
- **Negotiable sensory load** — the current router can compress output when
  explicit state calls for it, while stored defaults remain balanced density
  and medium sensory load. Low-sensory defaults, cross-host persistence, and
  complete dismissal/expiry behavior remain acceptance work.

See [executive function](/executive-function).

### It learns *you*, on your machine

`vanta tune lora` trains a local adapter from the operator decisions you've actually
accepted and rejected — real on-device (MPS / CUDA / CPU) training, nothing leaves the
machine. Plus auto skill-improvement, reflection-from-correction, and an evolving memory.
See [self-improvement](/self-improvement).

### Progressively autonomous without a global trust switch

The canonical migration target promotes workflows through R0 Observe, R1
Recommend, R2 Prepare, R3 Confirm, R4 Delegate, and R5 Autonomous delegate.
`R0`–`R5` are reserved exclusively for autonomy. Current legacy autonomy stores
have not yet been reconciled into this contract across hosts.

### Reachable from anywhere you already are

**22 registered messaging adapters from one gateway** — Telegram, Slack,
Discord, Signal, WhatsApp, iMessage, Matrix, LINE, Mattermost, IRC, ntfy,
Teams, Twitch, SMS, Zalo, Feishu, QQ, WeChat, WebChat, Nostr, Google Chat, and
Email. Telegram and ntfy have accepted live receipts; the rest require
platform-specific setup and live acceptance. See [comms & gateway](/comms-and-gateway).

### Any model, any host you control

Provider-agnostic: any OpenAI-compatible endpoint (custom base URL) plus Azure,
OpenRouter (200+ models), Ollama, OpenAI, Anthropic, and Gemini — and Vanta exposes its
own OpenAI-compatible proxy. Run it local, in a sandbox, in Docker, over SSH, or on a $5
VPS. The intended action-gateway contract is the same on each host; current
acceptance does not yet prove identical mediation for every effect path. See
[providers](/providers).

### Yours, not rented

**MIT-licensed and fully self-hosted.** Your data residency, no vendor lock-in, no hosted
service in the loop.

## Honest about the bar

Some capabilities are live-proven today; others need setup, integration hardening, or
end-to-end evidence. We label which is which rather than implying everything is turnkey.
The current audit also supersedes stale absolute safety and dependency claims. See
[what works now](/docs) and the acceptance record.
