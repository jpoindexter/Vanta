# Operator Signal

The operator signal is Vanta's compact abstract mark. It represents an alert point,
attention, and controlled action. It is intended for constrained identification: app icons,
selection/focus states, small packaging details, embroidery, and utility labels.

## Source files

| File | Use |
| --- | --- |
| `operator-signal-violet.svg` | default active/focus/attention expression on a Black or Bone field |
| `operator-signal-bone.svg` | one-color reverse on a Black field |
| `operator-signal-black.svg` | one-color mark on a Bone field or light stock |

## Use

- Minimum digital size: **24 px**. At 16–23 px, use only after target-platform testing.
- Minimum print size: **6 mm**. Minimum embroidery size: **8 mm**, subject to a stitch-out.
- Clear space: keep at least **6/48 of the artboard** clear on every side.
- Use as a compact mark only. Pair with the Vanta wordmark for formal identification.
- Use Violet for meaningful active/focus/operator state. Use Bone or Black for neutral,
  one-color applications.

Never stretch, outline, add glow, place it in a decorative repeat pattern, or use it as the
only indicator of an error, warning, or status. The geometry is a direction pending trademark
clearance and reproduction testing; it is not yet final legal artwork.

## Inline web use

```html
<img
  src="/brand/assets/marks/operator-signal-violet.svg"
  alt=""

```

Use empty `alt` when the nearby text already names the function. Give the image an accessible
name only when the mark itself communicates information not present in text.
