# Run the Vanta desktop

1. Prerequisites: Node 22+, `desktop-next` dependencies installed (`npm install` in `desktop-next`), the Electron binary downloaded, and a Vanta kernel binary at `<repo>/target/debug/vanta-kernel` (`cargo build` in the repo root).
2. Command, from `desktop-next`: `npm run vanta:app` (it builds the renderer and the Electron main first when `apps/desktop/dist` is missing; `--rebuild` forces it, `--hidden` keeps the window off screen).
3. It opens the real shell with the real Vanta server in a sandbox: its own `VANTA_HOME`, `HOME`, Electron user data and a throwaway git project (`acme-site`). Nothing under `~/.vanta` or the installed apps is touched.
4. Chats are answered by a canned local model (`vanta-proof`), so you see messages without a key. Closing the window deletes the sandbox.
5. You land on Home. Left: SESSIONS | BOTS tabs, New session, Home, Skills & tools, Connections, Outputs, Schedules, search, Pinned, Sessions, Cron jobs, then the profile row (home, +, import, ...) and the settings gear. Top right: Changes, Terminal, Browser, Files, then settings, layout editor, HUD, swap sides, right sidebar and More. Bottom: the status bar.
6. What works end to end in the real window: Files tree and preview, rename and delete (native confirmation), Review (stage, unstage, revert, commit through the approval card), the terminal pane (a line terminal: every command asks for approval first, and the card appears in the chat you are looking at), the mini window from the HUD button, find in page (⌘F), zoom and the menus, the tray and quick entry settings, image save, session export, profiles (create, set default, SOUL.md), schedules, tools on and off.
7. Known inert (present, the backend or native call is not wired): the Browser pane cannot load pages (webviewTag is off), Settings pages that read the config route (Model, Chat, Workspace, Safety, Browser, Memory, Voice, Advanced, Providers, Tools & Keys), the Bots roster (needs the profiles.list RPC), Messaging and Webhooks pages, Import session, updates, Project lanes (sessions carry no cwd).
8. Proofs, all hidden and off-screen (an Electron `--require` argument makes every window transparent and parked off-screen, and the dock icon is hidden):
   - `npm run vanta:reach` runs `tools/reachability.mjs`: seeds a sandbox (older, pinned, archived and bulk chats), drives every F-row of the inventory in the running app and writes `docs/proofs/reachability-full-<date>.md`. `--only=chrome,right,window,thread,profiles,composer,palette,settings,pages,seeded` runs groups and prints the rows; `PROOF_SHOTS=<dir>` saves a screenshot of every failure.
   - Native dialogs, Finder, the Trash and the default browser are stubbed in the main process (`tools/proof/native-stubs.mjs`); everything else is the real handler. The scripted model (`tools/mock-openai.mjs`) answers a message that starts with `slow`, `shell: <command>`, `clarify`, `fail`, `image`, `long` or `link` with the matching behaviour.
   - `npm run vanta:shots` writes `docs/proofs/restore/*.png` (the Hermes scenes, then the native scenes: Files, Review, terminal with an approval card, sidebar status glyphs, project chip menu, mini window).
