## 8. Things that will bite you

- The tool shell dies on long commands (exit 143/144): detach and poll a log.
- `vanta` resolves `tsx` from the current directory: run it from `vanta-ts/`.
- A bare `vanta desktop` now opens the app instead of serving the browser desktop. Scripts that need the server must pass an argument (for example a port and `--no-open`).
- `npm audit fix` crashed on the old symlinked `node_modules`; with the real install it should work, not re-checked.
- A blanket rename script once rewrote the license references and the copyright line; the packaging run caught it. If you rename anything in bulk, run the brand scan and a packaging run, and read the diff of the license and `NOTICE.md`.
- The reachability report prints verdicts but truncates failure notes at the first line, and its hard-coded "why" strings can be stale. Check the screenshot before believing a note.
- The headless launch gate refusing a worker ("needs the owner's approval to launch and no approval channel is open") is the design, not a bug.
- Do not read or copy credentials files (`~/.codex/auth.json`, the Claude keychain item). Use the CLIs and providers as they are.
