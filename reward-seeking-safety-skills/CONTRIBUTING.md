# Contributing

Keep contributions evidence-scoped and executable.

1. Do not add production holdout instances, expected outputs, credentials, or
   private model traces.
2. Separate a detector from a comparative measure in names, schemas, and docs.
3. Add a positive control and an inconclusive path to every new evaluation.
4. Keep skills under 500 lines and utilities under 200 lines.
5. Run `npm test` and `npm run check` before opening a pull request.

Pull requests should state the claim supported, the real path executed, and what
the evidence does not establish.
