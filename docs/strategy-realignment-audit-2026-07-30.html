The central trust gap

P0

Hook and control-plane bypass

A project write can create hook configuration that later executes host shell code outside the ordinary tool boundary.

P0

Credential exposure

Shell and code paths can inherit process credentials or read project secret-bearing files without a narrow broker.

P0

Audit integrity

Agent-readable project state currently contains material that can undermine the audit chain’s claim of independence.

P0

Incomplete capability boundary

The kernel assesses TypeScript-provided descriptions while TypeScript and extensions still perform many effects.

P1

Completion laundering

Desktop, CLI, TUI, memory, and verification paths do not yet consume one typed, evidence-backed terminal state.

P1

Operator fragmentation

Multiple stores, queues, modes, dashboards, commands, and agents obscure who owns work and what genuinely needs the user.

Documentation alignment is not implementation evidence. This pass can install a truthful strategy and build order; it cannot claim these runtime gaps are fixed.
